## 收录规范

1. 每条热点必须附来源链接与日期，禁止无源转述。
2. 季度性内容（如算力洞察）沉淀满一期后归档到对应篇章（硬件→`hw/`，方法→`paper/`），本目录保留索引。
3. 观点必须标注为观点，数据必须标注出处与年份。
