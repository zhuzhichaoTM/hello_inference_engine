> 写一个 Python 函数，判断一个整数是否为素数。
当然可以！下面是一个简单的 Python 函数，用于判断一个整数是否为素数：

```python
def is_prime(n):
    if n <= 1:
        return False
    if n <= 3:
        return True
    if n % 2 == 0 or n % 3 == 0:
        return False
    i = 5
    while i * i <= n:
        if n % i == 0 or n % (i + 2) == 0:
            return False
        i += 6
    return True

# 测试函数
print(is_prime(11))  # 应该返回 True
print(is_prime(15))  # 应该返回 False
```
