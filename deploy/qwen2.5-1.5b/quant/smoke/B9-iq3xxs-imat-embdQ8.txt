> 写一个 Python 函数，判断一个整数是否为素数。
您好！这是一个 Python 函数，用于判断一个整数是否为素数：

```python
def is_prime(num):
    if num <= 1:
        return False
    for i in range(2, num):
        if num % i == 0:
            return False
    return True
```

这个函数首先检查 num 是否小于等于 1，如果是的话，函数返回 False。然后，它会检查 num 是否能被 2 到 num-1 之间的任何数字整除。如果 num 能被这些数字之一整除，那么 num 不是素数，函数返回 False。否则，num 是素数，函数返回 True。
