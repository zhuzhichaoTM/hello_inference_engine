> 写一个 Python 函数，判断一个整数是否为素数。
要判断一个整数是否为素数，可以使用以下的Python函数：

```python
def is_prime(n):
    """判断一个整数是否为素数"""
    if n <= 1:
        return False
    if n <= 3:
        return True
    if n % 2 == 0 or n % 3 == 0:
        return False
    i = 5
    while i * i <= n:
        if n % i == 0 or n % (i + 2) == 0:
            return False
        i += 6
    return True
```

这个函数首先检查输入的整数是否小于等于1，如果是，则返回False，因为1和小于1的整数都不是素数
