# L8 · 评测、可观测性、功耗、安全与成本

本层承载端侧推理的质量/性能/功耗评测、可观测性、可靠性、安全隐私与成本资料。L8 作为独立的评测与运营章节，内容统一收敛在仓库根目录的 [`benches/`](../../benches/) 中；本目录保留为 L8 的业务地图占位入口，便于按 L0–L8 层级浏览。

**在业务地图中的位置**：对应[端侧大模型推理业务地图](../端侧大模型推理业务地图.md) §1.11；支撑业务流程 04 质量评测与验收、07 线上监控与容量治理、11 成本与能效优化、12 故障定位与恢复、13 安全隐私与可靠性治理，以及工程闭环的「2 性能基线」「5 收益量化」「6 回归验收」。

## 独立章节入口

- [benches/ 性能与评测篇](../../benches/)

## 章节范围（端侧口径）

- 质量评测：Tokenizer/Template 正确性、量化前后质量、多后端一致性、Prefix Cache 命中一致性
- 性能与能效：TTFT、ITL、Decode tok/s、峰值内存、平均功率、能效 tokens/Joule、热降频
- 端侧可观测性：Xcode Instruments / Android Studio Profiler / Perfetto / Snapdragon Profiler / Arm Streamline 等
- 可靠性：OOM 与被系统强杀、算子回退、热降频抖动、长跑资源泄漏
- 安全与隐私：数据不出端、Prompt Injection、模型加密与权重完整性、TEE
- 成本：设备摊销、能效与续航、模型体积与分发成本

新增 L8 文档和评测报告请优先放入 `benches/`，并在该目录 README 中补充索引；L8 的总体目标和能力清单仍以[端侧大模型推理业务地图](../端侧大模型推理业务地图.md)为准。
