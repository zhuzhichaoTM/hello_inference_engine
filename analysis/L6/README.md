# L6 · 端侧部署形态与工程化

本层承载把端侧引擎集成进真实设备与产品的工程化资料：移动端 App、PC/AI PC、嵌入式/IoT、车载/机器人/XR、浏览器端，以及分发、启动、体积、更新与稳定性。

**在业务地图中的位置**：对应[端侧大模型推理业务地图](../端侧大模型推理业务地图.md) §1.9；支撑业务流程 02 模型上线与交付、10 版本迭代与回归，以及工程闭环的「0 环境准备」「6 回归验收」。

## 建议沉淀

- App/固件集成：动态库集成、模型随包/按需下载、冷启动与 mmap 预热
- 模型打包/压缩/加密、体积控制、OTA 与增量更新、版本回滚
- 线程/核心调度与后台策略、多设备（SoC/内存档位）适配
- 端云边界判定（仅做卸载决策，不展开云端）

当前资料待持续补充，学习主线请先参考[端侧大模型推理业务地图](../端侧大模型推理业务地图.md)的 L6 章节。
