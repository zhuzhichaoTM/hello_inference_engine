## 一、与「源码版题库」的区别

| | 源码版 `../题库/` | **本版 `题库-原理业务版/`** |
|---|---|---|
| 提问角度 | 结构体/函数在哪、行号、字段值 | 它**为什么存在、何时生效、导致什么后果** |
| 典型题干 | "`supports_op` 定义在哪一行" | "某算子只改了执行逻辑没改能力声明，业务上会观察到什么现象" |
| 场景 | 源码精读 | 在线服务、长上下文、OOM、吞吐上不去、多卡不均 |
| 用途 | 对照源码查漏 | **方案设计 / 量化选型 / 性能调优 / 问题诊断** |

> 两版互补：源码版练"读得懂"，本版练"用得上"。**本版严禁源码定位题与行号**。

## 三、模块知识域

**模块1 · 核心架构（300）**
张量语义与 stride 影响 / 计算图原理与图复用 / 异构调度业务行为（何时拷贝、何时驻留）/
显存与主机内存管理特性 / 显存碎片成因与后果 / 上下文生命周期与并发隔离 /
异步语义与多流适用结构 / CUDA Graph 收益与兼容边界 / 后端抽象的设计目的 /
多卡业务约束与负载分配 / batch 与动态序列长度

**模块2 · 量化推理（350）**
量化数学原理与分组动机 / 量化家族比特-误差特征 / 权重量化 vs 激活量化 /
动态 vs 静态量化场景 / 精度-速度-显存三角取舍 / 误差来源与层间传播 /
困惑度与长上下文稳定性 / 反量化与低精度计算流程 / 对齐与访问行为 /
量化兼容性约束与回退代价 / 量化选型决策

**模块3 · 算子原理（200）**
核心算子数学逻辑（GEMM/GEMV、RoPE、Norm、Softmax、Attention）/
FlashAttention 与 online softmax 原理 / CUDA 执行模型（grid/block/warp、occupancy）/
存储层级与 bank conflict / 算子融合原理与触发条件 / 自定义算子接入业务约束 /
广播与分片 / Tensor Core 触发条件与限制 / 异步预取与 PDL

**模块4 · 性能调优（150）**
算力受限 vs 访存受限识别 / 显存优化与 KV cache 管理 / batch 与上下文长度权衡 /
在线低延迟 vs 离线吞吐选型 / 异步与预取 / 多卡瓶颈（NVLink vs PCIe、负载不均）/
量化与融合的组合调优 / 性能指标与瓶颈定位 / 编译选项的业务效果 / 调优方法论

## 五、题目规范

每题严格五段式：

```text
### 第 N 题
【题型：单选题/多选题】【难度：基础/进阶/高阶】
【题干】……（优先结合真实业务场景）
【选项】A. … B. … C. … D. …（多选可到 E）
【正确答案】X 或 XY（大写）
【详细解析】
1. 核心原理 —— 底层机制
2. 选项分析 —— 逐项说明正误原因（干扰项须为真实工程误区）
3. 业务延伸 —— 场景取舍 / 踩坑点 / 学一题会一类
```

**出题硬约束**：
1. 严禁源码定位题（不问文件、不问行号、不问字段名）
2. 干扰项必须是真实误区，不设无意义选项
3. 单选恒 1 个答案，多选恒 ≥2 个答案
4. 不引入 TensorRT / PyTorch / ONNX Runtime / vLLM 等他框架作为考点
5. 每题独立考点，模块内按难度升序

## 六、使用方式

