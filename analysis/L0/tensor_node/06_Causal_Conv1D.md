## 3. 数学定义

**深度可分离因果卷积**（depthwise = 每通道独立一维卷积核；causal = 只看当前与过去）：

$$y_t^{(c)} = \sum_{k=0}^{K-1} w_k^{(c)}\, x_{t-K+1+k}^{(c)},\qquad K=\texttt{conv\_kernel}=4$$

- 通道数 $C = 10240$（= `attn_qkv` 输出维 = 2048 Q + 2048 K + 6144 V）
- 核长 $K = 4$（`ssm.conv_kernel = 4`）

**因果性**：$y_t$ 仅依赖 $x_{t-3},x_{t-2},x_{t-1},x_t$，不回看未来。

## 6. 推理链路位置

```
循环层(blk∈{0,1,2,4,…,62}):
  x → RMSNorm → attn_qkv GEMM → [T,10240] → Split(算子17)
        ├─ Q 分支(2048) → L2Norm(算子08)
        ├─ K 分支(2048) → [本算子 Conv1D] → SiLU(算子04) → L2Norm → DeltaRule(算子07)
        └─ V 分支(6144) → DeltaRule(算子07)
```

- **上游**：算子 01（`attn_qkv` GEMM）、算子 17（Split）
- **下游**：算子 04（SiLU 激活）、算子 07（DeltaRule）
- 报告 §4.1 #4 记录「循环层 conv1d 后激活 48」→ Conv1D 输出直接送 SiLU。

## 7. Prefill / Decode 差异

| | Prefill | Decode |
|---|---|---|
| 形态 | 因果一维卷积（窗口 4），整段 $T$ 并行 | 单点，**读 conv 状态缓存** |
| 计算 | $T\times10240\times4$ MAC | $10240\times4$ MAC |
| 状态 | 需保留末尾 3 帧 | 状态 $[3,10240]$ 滚动更新 |
| 瓶颈 | 相对 DeltaRule 开销小 | **与 DeltaRule 串联在扫描关键路径** |

---

## 8. 实现要点与融合建议（§4.2）

- 报告族归类：序列算子（与 DeltaRule / SDPA / RoPE 合并计 130），**★★★ 延迟关键路径**。
- 实现要点：
  - depthwise，**不跨通道**（避免变成全连接）。
  - causal：prefill 需左侧 pad $K-1=3$；decode 用持久状态。
  - 与 `ssm_a`/`ssm_dt.bias` 无关（那是衰减门，走算子 09）。

---

## 9. 性能特征

- 每 token 每层 FLOPs：$10240\times4\times2 = 81{,}920$ ≈ **0.082 MFLOPs**。
- 48 层 → ≈ 3.9 MFLOPs/token，**对线性层 52.1 GFLOPs 可忽略**。
- 但位于 DeltaRule 串行扫描的前置（见文档 07），**延迟不可忽略**。

## 11. 最小参考实现（伪代码）

```cpp
// 报告 §4.1 算子#6：ssm_conv1d.weight [4,10240] f32，depthwise causal k=4
// Prefill: x[T,C] -> y[T,C]，左侧 zero-pad K-1=3
void causal_conv1d_depthwise(const float* x, const float* w /*[K,C]*/, float* y, int T, int C, int K=4) {
    for (int c = 0; c < C; ++c)
        for (int t = 0; t < T; ++t) {
            float acc = 0.f;
            for (int k = 0; k < K; ++k) {
                int src = t - (K-1) + k;                 // 因果窗口：只看 ≤ t
                if (src >= 0) acc += w[k*C + c] * x[src*C + c];
            }
            y[t*C + c] = acc;
        }
}
// Decode: 维护状态 state[K-1=3, C]，新 token 拼到末尾、弹出首位
```
