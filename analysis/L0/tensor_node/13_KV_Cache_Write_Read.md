## 3. 数学定义

- **Write**（每步）：将当前 K、V 追加到缓存

$$K_{cache}[t] \leftarrow k_t,\qquad V_{cache}[t] \leftarrow v_t$$

- **Read**（SDPA 时）：读出 $[0,t]$ 全部历史

$$K_{read}=K_{cache}[0:t],\qquad V_{read}=V_{cache}[0:t]$$

**容量公式（报告 §六）**：

$$\text{元素数}=17\ \text{层}\times2\ (\text{K,V})\times4\ \text{头}\times256\ \text{dim}\times262144\ \text{ctx}=9.13\times10^{9}$$

## 6. 推理链路位置

```
全注意力层(blk=3,7,…,63) / MTP(blk.64):
  K = MRoPE(attn_k GEMM 输出)  ──► [KV-Cache Write]
  V = attn_v GEMM 输出         ──► [KV-Cache Write]
                                        │
                     [KV-Cache Read] ◄──┘ ──► SDPA(文档12)
```

- **上游**：算子 11（RoPE，仅作用于 K）、算子 01（`attn_v`）
- **下游**：算子 12（SDPA）

## 7. Prefill / Decode 差异

| | Prefill | Decode |
|---|---|---|
| Write | 一次写入 $T$ 个位置 | 每 token 追加 1 个位置 |
| Read | $T\times T$ 内（分块） | $1\times T_k$（全历史） |
| 瓶颈 | 写入带宽 | **读取访存**：每 token 读全历史 KV |
| 主控因素 | 序列长度 | **上下文长度（262144）** |

---

## 8. 实现要点与融合建议（§4.2）

- 报告族归类：状态算子，**★★★ 长上下文显存瓶颈**。
- 建议（§六）：
  - **必须开 `--cache-type-k q8_0`**；或 `-ctk q4_0`。
  - V100S 的 FA 支持 **`q8_0-q8_0`** 组合。
  - KV 量化是 262144 上下文可运行的**前提**（f16 会 OOM，见文档 14 显存预算）。

## 9. 性能特征

| 指标 | f16 | q8_0 | q4_0 |
|---|---:|---:|---:|
| 显存 | 18.25 GB | 9.70 GB | 5.14 GB |
| 每 token 读取 | 18.25 GB | 9.70 GB | 5.14 GB |

- **decode 关键洞察**：$N_{ctx}=262144$ 时，**KV 读取流量（18.25 GB, f16）> 权重流量（16.80 GB）** → KV 量化后（q8_0 = 9.70 GB）权重重新成为访存主体。
- 显存预算（文档 14）：权重 16,021 MiB + f16 KV 17,404 MiB > V100S 32,494 MiB → **必 OOM**。

## 11. 最小参考实现（伪代码）

```cpp
// 报告 §4.1 算子#13：仅 17 层有 KV Cache；FA_QUANTS=q4_0/q8_0/f16/bf16
// 单层缓存布局 [2(K,V), ctx=262144, n_kv_head=4, head_dim=256]
struct KVCache { std::vector<uint8_t> k, v; int len = 0; int type; /* f16/q8_0/q4_0 */ };

void kv_write(KVCache& c, const float* k_t /*[4,256]*/, const float* v_t, int t) {
    quant_store(c.k, t, k_t, 4*256, c.type);      // 追加写入位置 t
    quant_store(c.v, t, v_t, 4*256, c.type);
    c.len = t + 1;
}
void kv_read(const KVCache& c, int t_end, float* k_out, float* v_out) {
    quant_load(c.k, 0, t_end, k_out, c.type);     // 读出 [0, t_end) 全历史 → SDPA
    quant_load(c.v, 0, t_end, v_out, c.type);
}
// 显存: 17 层 × 2 × 4 × 256 × 262144 元素；f16=18.25GB, q8_0=9.70GB, q4_0=5.14GB
```
