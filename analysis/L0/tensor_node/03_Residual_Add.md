## 3. 数学定义

$$y = x + f(x)$$

其中 $f(x)$ 为注意力分支或 FFN 分支的输出。

**每 block 两处**（报告 §2.2 拓扑）：

$$x' = x + \text{Attn}\big(\text{RMSNorm}(x)\big),\qquad x'' = x' + \text{FFN}\big(\text{RMSNorm}(x')\big)$$

> 注意：循环层中 Attn 分支 = SSM/DeltaNet 分支；全注意力层中 Attn 分支 = GQA 分支。

## 6. 推理链路位置

```
x ──┬───────────────────────────────────► Add#1 ──┬──► Add#2 ──► 下一 block
    └─ RMSNorm → Attn分支 ────────────────────────┘         ▲
                    └─ RMSNorm → FFN分支 ────────────────────┘
```

- **Add#1**：注意力（或 SSM）分支输出 + 残差
- **Add#2**：FFN 分支输出 + 残差
- **上游**：算子 01 GEMM（`ssm_out` / `attn_output` / `ffn_down`）
- **下游**：算子 02 RMSNorm（下一子层前置）

## 8. 实现要点与融合建议（§4.2）

- 报告族归类：逐元素（与 Mul/SiLU/Sigmoid/Softplus 合并计 472 个），**★★ 全部可 kernel-fuse**。
- 建议：与相邻 RMSNorm（算子 02）融合，减少一次 $[T,5120]$ 激活的读写往返。

## 9. 性能特征

- FLOPs：$5120$ 次加法/行；$N$ 行时 $5120N$。
- 访存：读 2×$[T,5120]$ + 写 $[T,5120]$，**纯 memory-bound**，无权重流量。
- 在 1567 节点中占 **130（8.3%）**，但**几乎不贡献算量**。

## 11. 最小参考实现（伪代码）

```cpp
// 报告 §4.1 算子#3：每 block 2 次；无权重张量
void residual_add(const float* x, const float* f, float* y, int n) {
    for (int i = 0; i < n; ++i) y[i] = x[i] + f[i];   // n = 5120
}
// 调用点：x' = Add(x, Attn(RMSNorm(x)));  x'' = Add(x', FFN(RMSNorm(x')))
```
