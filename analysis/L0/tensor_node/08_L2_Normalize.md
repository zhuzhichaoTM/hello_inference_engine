## 3. 数学定义

沿 head_v_dim = 128 做单位化投影（**无乘性 scale 权重**）：

$$\hat{u} = \frac{u}{\lVert u\rVert_2 + \delta},\qquad u\in\mathbb{R}^{128}$$

> 注：报告仅记「对 Q/K 做 L2 归一」，未给 ε/δ 项，亦未给分母加 eps 的确切形式 → 本文档以 $\delta$ 占位并标注为"报告未明确"。

## 6. 推理链路位置

```
循环层:
  attn_qkv GEMM → Split:
    ├ Q 分支 → [L2Norm#1] ───────────────┐
    ├ K 分支 → Conv1D → SiLU → [L2Norm#2]┤ → DeltaRule(文档07) S←S·α+β·(k⊗v)
    └ V 分支 ──────────────────────────────┘
```

- **上游**：算子 01（Q 投影）、算子 06+04（K 经 conv+SiLU）
- **下游**：算子 07（DeltaRule 用 L2 归一后的 q、k 做外积/读出）
- **设计意图**（DeltaNet 结构约定，报告 §4.1 #8）：L2 归一让 q、k 落在单位球上，使 $\beta(k\otimes v)$ 的秩 1 更新幅度可控（线性注意力稳定性来源）。

## 8. 实现要点与融合建议（§4.2）

- 报告族归类：归一化（RMSNorm 216 + L2Norm 96 = **312**），**★★ 融合进 GEMM 前处理**。
- 建议：将 L2Norm 与 DeltaRule 专用 kernel（文档 07 的 `GGML_OP_GATED_DELTA_NET`）**合并**，避免 96 个独立节点 launch。

---

## 9. 性能特征

- FLOPs：每元素约 1 乘方 + 1 加 + 1 sqrt + 1 除 ≈ 4 FLOPs；$16\times128\times2=4096$ 元素/层 → ≈ 16 KFLOPs/层。
- 48 层 → ≈ 0.77 MFLOPs/token，**可忽略**。
- 节点数占 96/1567 = 6.1%，**属数量大算量小、应被 fuse 的类别**。

## 11. 最小参考实现（伪代码）

```cpp
// 报告 §4.1 算子#8：线性注意力 Q/K 的 per-head L2 归一，无权重，96 次
// x: [T, n_head=16, head_dim=128]
void l2_norm_per_head(float* x, int T, int n_head, int head_dim, float eps=1e-6f /*报告未给，占位*/) {
    for (int t = 0; t < T; ++t)
        for (int h = 0; h < n_head; ++h) {
            float* p = x + ((size_t)t*n_head + h)*head_dim;
            float ss = 0.f;
            for (int i = 0; i < head_dim; ++i) ss += p[i]*p[i];
            float r = 1.0f / sqrtf(ss + eps);
            for (int i = 0; i < head_dim; ++i) p[i] *= r;
        }
}
```
