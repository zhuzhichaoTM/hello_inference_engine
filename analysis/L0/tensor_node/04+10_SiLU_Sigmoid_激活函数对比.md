### 2.3 ⚠️ 计数巧合警示（避免误读为恒等式）

## 3. 数学定义与逐点性质对比

$$\text{SiLU}(z) = z\cdot\sigma(z) = \frac{z}{1+e^{-z}} \qquad\qquad \text{Sigmoid}(z) = \sigma(z) = \frac{1}{1+e^{-z}}$$

### 3.1 逐点性质对照表

| 性质 | SiLU / Swish | Sigmoid |
|---|---|---|
| 值域 | $(-0.2785,\ +\infty)$ | $(0,\ 1)$ |
| 单调性 | **非单调**：负半轴有极小点 $z^\*\approx-1.2785$，$f(z^\*)\approx-0.2785$ | **严格单调递增** |
| 一阶导 | $\sigma(z)\big(1+z\,\sigma(-z)\big)$ | $\sigma(z)\big(1-\sigma(z)\big)$ |
| 饱和行为 | 仅**负向**饱和（$z\to-\infty\Rightarrow f\to 0^-$）；**正向近似恒等**（$z\gg0\Rightarrow f\approx z$，导数 $\to1$） | **双向**饱和（$\lvert z\rvert\to\infty\Rightarrow$ 导数 $\to0$） |
| 符号保持 | 是（$z<0\Rightarrow f<0$） | 否（输出恒正） |
| 零点 | $f(0)=0$ | $f(0)=0.5$ |
| 语义定位 | **有符号的特征非线性**（可放大幅度、可产生负激活） | **有界的开关/掩码**（只能衰减到 0、最大 1） |

### 3.2 核心分水岭

> **SiLU 是"保留符号与幅度的特征变换"；Sigmoid 是"(0,1) 区间的乘性掩码生成器"。**

这一差异直接决定二者在报告中的落点，也是 §4 全部判据的出发点。

## 4. 对比分析：为什么同一模型采用两种不同激活函数

> **本节为合并文档的核心新增章节。**
> 报告中**直接记录**的内容（张量、次数、公式、族归类）标注为"报告直述"；**由报告已有结构推出的解释**标注为"结构推导"。所有推导只锚定报告内的张量形状、算子链路与公式，不引入报告外的模型设定。

### 4.1 一句话结论

| 激活 | 在报告中的角色 | 报告判据 |
|---|---|---|
| **SiLU** | 出现在**数据通路**上，做特征非线性变换（宽通路：17408 / 10240 维） | §4.1 #4 两处落点均记为"**激活**" |
| **Sigmoid** | 出现在**门控支路**上，生成 (0,1) 掩码供 Mul 消费 | §4.1 #5 明记 "Q-Gate(**sigmoid 后**)"；#10 两处落点均记为"**门控**" |

### 4.2 判据一：功能角色不同 —— 特征量 vs 门控量（报告直述）

- **SiLU 的 113 次全部是"激活"**：FFN 激活（65）+ conv1d 后激活（48）。
- **Sigmoid 的 65 次全部是"门控"**：Q-Gate（17）+ β 门控（48）。
- 输出去向的关键差异（报告 §4.1 #5）：
  - **Sigmoid 的输出 100% 被 Mul 消费**：Q-Gate 17、β 门控 48 均出现在 §4.1 #5 的 Mul 清单里，且 #5 明确写了 "Q-Gate(**sigmoid 后**)"。
  - **SiLU 的输出只有一部分被 Mul 消费**：FFN 那 65 次进入 §4.1 #5 的 "FFN 门控 65"；另外 **48 次 conv1d 后激活不在 Mul 清单中**，而是进入 DeltaRule 的数据通路（§4.1 #6 → #4 → #7）。

→ **Sigmoid 是纯门控量生成器（输出只为做乘性控制）；SiLU 是特征量生成器**（在 FFN 中它同时充当"门"与"被乘的数值"本身）。

### 4.3 判据二：为什么 FFN 用 SiLU 而不是 Sigmoid（结构推导 + 报告证据）

FFN 是 5120 → **17408** → 5120 的**升维-降维**结构（`ffn_gate` / `ffn_up` / `ffn_down`，报告 §2.3），其门控形态为：

$$\text{FFN}(x) = W_{down}\Big(\underbrace{\text{SiLU}(W_{gate}x)}_{(\ast)} \odot (W_{up}x)\Big)$$

- $(\ast)$ 支路**同时充当"门"和"被乘的数值"**：必须保留 $W_{gate}x$ 的**符号与幅度**。
- （结构推导）若把 $(\ast)$ 换成 Sigmoid：该支路被压到 $(0,1)$ 且**全正**（丢失符号），大正值区**饱和**（信息被压扁）→ 17408 维升维空间的表达能力被截断。
- **报告层面证据**：§4.1 #5 明确把 FFN 的 Mul 记为"**FFN 门控**"，与 §4.1 #4 的 SiLU 配对 → 这正是 **SwiGLU（Swish-Gated Linear Unit）** 的定义式。

### 4.4 判据三：为什么循环层 conv1d 之后也用 SiLU（结构推导）

- `ssm_conv1d`（§4.1 #6「线性注意力分支的短卷积，通道数 **10240**」）输出是 10240 通道的**特征**，其后接 L2Norm → DeltaRule（§4.1 #8 → #7）。
- （结构推导）该路径上的 k 需参与外积 $k\otimes v$（§4.1 #7）。若用 Sigmoid 把每一维压成正数，会改变 k 的符号结构，与报告 §4.1 #8 所记"对 Q/K 做 L2 归一"（只改模长、不改方向）的设计意图相冲突；SiLU 的有符号特性与之相容。

### 4.5 判据四：为什么门控必须用 Sigmoid（报告证据 + 结构推导）

**① Q-Gate**（`attn_q.weight` 后 6144 维，报告 §2.3）作用于 SDPA 输出：

- （结构推导）语义是"对注意力输出做**可学习的衰减/掩码**"→ 需要 $\in(0,1)$ 的乘性系数，能衰减到 0（等效关断）。
- SiLU 值域含负区且**上无界** → 会反号/放大，不符合掩码语义。

**② DeltaNet β 写入门**（`ssm_beta.weight`，报告 §2.3；进入 §4.1 #7 递推式）：

$$S \leftarrow S\cdot\alpha \;+\; \beta\,(k\otimes v)$$

- （结构推导）$\beta$ 是**写入强度**，递推式要求其**有界**，否则状态 $S$ 逐 token 累积会发散。Sigmoid 的 $(0,1)$ 界恰好给出"写入增益 $\le1$"的稳定性保证 —— 这正是 **Gated** DeltaNet 中 "gated" 的由来。
- **报告佐证**：§4.1 #10 明确 β 门控走 **Sigmoid**。

### 4.6 判据五：模型里其实有**三种**激活，各司其职（报告直述）

报告 §4.1 记录的第三个激活是 **Softplus / Exp（#9，48 次）**，用于**衰减门**：

$$g = -\exp(A_{log})\cdot\text{softplus}(a + dt\_bias) \;\le\; 0$$

| 激活 | 落点 | 需要的数学性质 | 为什么非它不可（结构推导） |
|---|---|---|---|
| **SiLU**（#4，113 次） | FFN 激活、conv1d 后 | 有符号、上无界、大正值近似恒等 | 特征通路需保幅保号，Sigmoid 会把通路压扁 |
| **Sigmoid**（#10，65 次） | Q-Gate、β 写入门 | $(0,1)$ 有界、单调 | 掩码 / 写入增益必须受限，SiLU 会放大 |
| **Softplus/Exp**（#9，48 次） | 衰减门 $g$ | 非正、对数域 | 衰减系数需 $\le0$，既非 $(0,1)$ 掩码也非无界 |

→ **同一模型采用多种激活，不是因为"重复实现"，而是因为三类语义（特征变换 / 有界门 / 衰减门）对值域与饱和行为的要求互斥**：单一激活无法同时满足——Sigmoid 做 FFN 会压扁升维特征；SiLU 做 β 门会让递推发散；两者做衰减门都得不到 $g\le0$ 的对数域语义。

> 衰减门（算子 #9）的完整拆解见 [`09_Softplus_Exp.md`](./09_Softplus_Exp.md)。

### 4.7 判据六：分布位置与元素量级不同（§9.3 + §2.3 推导）

| 维度 | SiLU | Sigmoid |
|---|---|---|
| 落点通路 | **宽通路**：17408（FFN）、10240（conv） | **窄门路**：6144（Q-Gate）、48（β/头） |
| 每次元素量 | 17408 或 10240 | 6144 或 48 |
| 层型覆盖 | 公共(65) + 循环(48) | 循环(48) + 全注意力(16) + MTP(1) |
| 总元素量级 | 高 | 低（约低 2 个数量级） |

→ SiLU 处在**算量/访存更重**的宽通路上，Sigmoid 处在**极窄**的门控支路上。

### 4.8 判据七：性能与融合策略**不**因激活类型分叉（报告 §4.2）

报告 §4.2 把 `SiLU` 与 `Sigmoid` 与 `Add / Mul / Softplus` 合并为**同一个"逐元素"族（472 个节点，★★ 全部可 kernel-fuse）**。

→ **选型动机是功能性的，不是性能性的**：两者在 kernel 融合上的处理方式相同（都并入相邻 kernel），不存在"因为性能才用两种激活"的解释。

### 4.9 判据八：数值风险的差异（§六 + 推导）

报告 §六：V100S CC 7.0 **无 BF16 Tensor Core、无 FP8** → 走 **FP16 激活**。

| 项 | SiLU | Sigmoid |
|---|---|---|
| 输出范围 | $(-0.2785,+\infty)$，**上无界** | $(0,1)$，**有界** |
| FP16 安全性 | 大正值区近似恒等 → 输出可能接近输入量级，需关注 FP16 动态范围（**结构推导**，报告未给激活统计） | 输出恒在 $(0,1)$，FP16 绝对安全 |
| 饱和区行为 | 负向饱和（梯度 $\to0$） | 双向饱和（梯度 $\to0$） |

→ **Sigmoid 对低精度更友好**（有界），**SiLU 承担 FP16 动态范围风险**；这一差异使 §4.5 的"门控用 Sigmoid"选择在数值上也是有利的。

### 4.10 对比分析小结

| # | 判据 | SiLU | Sigmoid | 来源 |
|---|---|---|---|---|
| 1 | 功能角色 | 特征量（数据通路） | 门控量（100% 被 Mul 消费） | 报告直述 |
| 2 | FFN 门控形态 | SwiGLU 的门控支路本身 | — | 报告直述（#4 + #5 配对） |
| 3 | conv1d 后 | 有符号，保 k 方向 | — | 结构推导 |
| 4 | 有界性要求 | 上无界（保幅） | $(0,1)$（保稳） | 报告直述 + 结构推导 |
| 5 | 三激活分工 | 特征变换 | 有界门 | 报告直述（含 #9） |
| 6 | 通路宽度 | 17408 / 10240 | 6144 / 48 | §2.3 推导 |
| 7 | 融合策略 | 同族同优先级 | 同族同优先级 | 报告直述（§4.2） |
| 8 | FP16 风险 | 需关注动态范围 | 安全 | §六 + 推导 |

**结论（报告层面可支撑的表述）**：报告中 SiLU 与 Sigmoid 的落点互不重叠、语义互不替代——SiLU 只出现在需要**保留符号与幅度**的特征通路上（FFN 升维激活、线性注意力 conv 分支），Sigmoid 只出现在需要**有界乘性控制**的门控支路上（Q-Gate、DeltaNet β 写入门）。二者并非同一功能的两种实现，而是**分工不同的两类算子**。

## 7. 推理链路位置（并列）

```
【公共分支 — SiLU 65】
  ffn_gate GEMM [5120,17408] → [SiLU] ─┐
                                        ├─ Mul(§4.1 #5, 65) → ffn_down GEMM
  ffn_up   GEMM [5120,17408] ──────────┘

【循环层 — SiLU 48 + Sigmoid 48】
  attn_qkv GEMM → Split:
      ├ Q(2048) → L2Norm ─────────────────────────────────┐
      ├ K(2048) → Conv1D(§4.1 #6) → [SiLU] → L2Norm ───────┤
      └ V(6144) ───────────────────────────────────────────┤
                                                           ├─ DeltaRule: S ← S·α + β·(k⊗v)
  ssm_alpha·x → Softplus/Exp(§4.1 #9) = α ──────────────────┤
  ssm_beta·x  → [Sigmoid] = β → Mul(§4.1 #5, 48) ───────────┘
```

## 9. 实现要点与融合建议（§4.2 / §六）

- 报告族归类：**逐元素（与 Add / Mul / Softplus 合计 472），★★ 全部可 kernel-fuse**。
- 融合方案：
  - SiLU（FFN）→ 与 `ffn_gate` / `ffn_up` GEMM 输出 + 后续 Mul **三者融合为 SwiGLU kernel**。
  - SiLU（conv1d 后）→ 融入 Conv1D kernel 的尾部。
  - Sigmoid（Q-Gate）→ 与 SDPA epilogue + Mul 融合。
  - Sigmoid（β）→ 融入 `GGML_OP_GATED_DELTA_NET` 专用 kernel（§六：DeltaNet 不要拆成小算子）。

## 10. 性能特征

| 指标 | SiLU | Sigmoid |
|---|---|---|
| 每元素 FLOPs | ≈ 3–4（1 乘 + 1 sigmoid） | ≈ 3（1 exp + 1 加 + 1 除） |
| 每次元素量 | 17408（FFN）/ 10240（conv） | 6144（Q-Gate）/ 48（β） |
| 节点占比 | 113 / 1567 = **7.2%** | 65 / 1567 = **4.1%** |
| 相对 52.1 GFLOPs/token 线性层 | < 1% | < 1% |

→ 两者**节点数量可观（合计 178 / 1567 = 11.4%）但算量可忽略**，是**融合收益最高的类别之一**。

## 11. 数值精度与量化约束

| 项 | SiLU | Sigmoid | 依据 |
|---|---|---|---|

## 12. 最小参考实现（C++）

```cpp
// 报告 §4.1 算子#4（SiLU，113 次）与 #10（Sigmoid，65 次）；两者均无权重张量
#include <cmath>

// ---- SiLU / Swish：值域 (-0.2785, +inf)，有符号，正向近似恒等 ----
// 落点：FFN 激活 [T,17408]×65；循环层 conv1d 后激活 [T,10240]×48
void silu(const float* z, float* out, int n) {
    for (int i = 0; i < n; ++i) out[i] = z[i] / (1.0f + expf(-z[i]));   // z * sigmoid(z)
}

// ---- Sigmoid：值域 (0,1)，单调、双向饱和，纯门控量 ----
// 落点：Q-Gate [T,24,256]×17；DeltaNet β 写入门 [T,48]×48
void sigmoid(const float* z, float* out, int n) {
    for (int i = 0; i < n; ++i) out[i] = 1.0f / (1.0f + expf(-z[i]));
}

// ---- 用法对照 ----
// SwiGLU FFN:  y = ffn_down( silu(ffn_gate·x) ⊙ (ffn_up·x) )   ← SiLU 作特征 + 门控被乘数
// Q-Gate:      y = sigmoid(attn_q[:,6144:]) ⊙ sdpa_out         ← Sigmoid 作 (0,1) 掩码
// β 写入门:    S ← S·α + sigmoid(ssm_beta·x) ⊗ (k⊗v)           ← Sigmoid 保证写入增益 ≤ 1
```

| $f(0)$ | $0$ | $0.5$ |
| $f(-1.2785)$ | $\approx -0.2785$（极小点） | $\approx 0.2178$ |
| $f(10)$ | $\approx 9.9995$（近似恒等） | $\approx 0.99995$（饱和） |
| 符号 | 与 $z$ 同号 | 恒正 |
