## 3. 数学定义（视图变换，非数值计算）

**Split**：沿最后一维切分

$$[T, 10240] \rightarrow \big([T,2048]_{Q},\ [T,2048]_{K},\ [T,6144]_{V}\big)$$

$$[T, 12288] \rightarrow \big([T,6144]_{Q},\ [T,6144]_{Q\text{-}Gate}\big)$$

**Reshape**（多头重排）：

$$[T, 6144] \rightarrow [T, 24, 256],\qquad [T, 1024]\rightarrow[T,4,256]$$

**Transpose**：为 SDPA 准备 `[B,H,T,D]` 布局（具体轴序报告未给）。

## 8. 实现要点与融合建议（§4.2 / §9.4）

- 报告族归类：胶水算子，**★ 融合进相邻 kernel**。
- 建议：
  - Split 若为**连续切分** → 可用视图（零拷贝）。
  - 多头重排（Reshape/Transpose）→ 融入 GEMM 的 **stride 设置**或 SDPA 的输入布局，避免物理搬运。
  - 报告 §9.4 强调本类是**节点计数口径**的敏感项，工程上**全部应被 fuse**。

---

## 9. 性能特征

- FLOPs：0（若为视图）/ 纯拷贝（若为物理重排）。
- 访存：物理重排时读+写 $[T,\text{dim}]$；fuse 后为 0。
- 节点占 65/1567 = 4.1%，**是"数量虚高"的典型**（报告 §9.4 口径修正对象）。

## 11. 最小参考实现（伪代码）

```cpp
// 报告 §4.1 算子#17：QKV 拆分、多头重排（胶水算子），65 次；无权重
// 循环层： [T,10240] → Q[T,2048], K[T,2048], V[T,6144]（连续切分，可用指针偏移零拷贝）
void split_qkv(const float* qkv /*[T,10240]*/, const float** Q, const float** K, const float** V, int T) {
    *Q = qkv + 0;                 // 前 2048
    *K = qkv + 2048;              // 中 2048
    *V = qkv + 4096;              // 后 6144
}
// 全注意力： [T,12288] → Q[T,6144] ‖ QGate[T,6144]
void split_q_qgate(const float* q, const float** Q, const float** QGate) {
    *Q = q; *QGate = q + 6144;
}
// 多头重排： [T,6144] → [T,24,256]，视图（stride = {6144,256,1}），无需物理拷贝
```
