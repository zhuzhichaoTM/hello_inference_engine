## 六、全局边界说明

1. **次数口径**：§3.2 / §4.1 的算子节点数是按 **llama.cpp 图节点粒度**的估计值，报告自身标注 **精度 ±5–10%**；权重块数 866（506 + 360）为日志直出的确定值。
2. **不含独立 Dequant 算子**：报告 §5.4 明确推理期由量化引入的算子只有反量化，且**已融合进 MatMul kernel**（`dequantize_row_q4_K` 内联），**不单独成节点** → 本字典 17 类中**无独立 dequant 项**。
3. **Gated DeltaNet 循环层不是标准 SDPA**：循环层不做 $O(n^2)$ 注意力，其核心为算子 07；SDPA（算子 12）与 KV-Cache（算子 13）在循环层出现次数均为 **0**。
4. **不在本字典范围**：tokenizer、mmproj 多模态分支、量化期离线逻辑（张量分派 / imatrix 加权 / 块编码，报告 §5.4 明示非推理算子）、端到端性能基线（报告 §7 列为未覆盖）。
5. **V100S 约束贯穿全篇**：CC 7.0 无 BF16 Tensor Core、无 FP8；反量化 + FP16 GEMM 混合路径；避免 BF16 累加、用 FP16 激活（§六）。
