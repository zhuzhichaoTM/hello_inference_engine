# L5 · 端侧推理引擎与框架

本层承载端侧推理引擎的选型、部署、后端覆盖与调优资料，覆盖 llama.cpp/ggml、MNN、ncnn、TNN、TFLite/LiteRT、ONNX Runtime、ExecuTorch、Core ML/MLX、OpenVINO、TensorRT、QNN、RKNN、TVM/MLC-LLM、WebLLM 等引擎。

**在业务地图中的位置**：对应[端侧大模型推理业务地图](../端侧大模型推理业务地图.md) §1.8；支撑业务流程 01 模型选型与部署规划、03 硬件与推理后端适配、09 性能分析与优化，以及工程闭环的「0 环境准备」「4 优化实施」。

## 建议沉淀

- 引擎选型矩阵：后端覆盖（CPU/GPU/NPU）、量化类型、动态 Shape、多模态、包体积、冷启动
- 同一模型跨引擎部署对比（时延/内存/功耗）
- 引擎通用机制：模型加载与 mmap、图优化与算子融合、Backend/Delegate/EP 抽象与回退
- 为引擎编写自定义算子/后端扩展
