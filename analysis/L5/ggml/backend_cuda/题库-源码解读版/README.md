## 五、题目规范

每题严格五段式：

```text
### 第 N 题
【题型：单选题/多选题】【难度：基础/进阶/高阶】
【题干】……
【选项】A. … B. … C. … D. …（多选可到 E）
【正确答案】X 或 XY（大写）
【详细解析】
1. 核心考点 —— 讲原理 + 给源码锚点
2. 错项分析 —— 逐项说明错误原因（含高频易错点）
3. 落地补充 —— 工程实操 / 学一题会一类
```

**反幻觉约束**：所有行号锚定本机 ggml v0.25.3 源码实测；不确定处以函数名定位，不编造行号。
